## Welcome to the Mountain Ecology and Biogeography Lab's GitHub!
The [Mountain Ecology and Biogeography Lab](mountain-eco-lab.squarespace.com), or Mt. Bio Lab at the University of Colorado, Boulder is led by Dr. Sisimac Duchicela. We study how humans impact landscapes from a vegetation perspective. As part of both the [CU Geography department](https://www.colorado.edu/geography/) and the [Institute of Arctic and Alpine Research](https://www.colorado.edu/instaar/) our work spans many disciplines. Check out [our website to learn more!](mountain-eco-lab.squarespace.com)

## Github Organization
This GitHub organization is home to all coded workflows related to active and archived projects from the Mt. Bio Lab. This is a private organization please reach out if you are collaborating with us and need to be added.
